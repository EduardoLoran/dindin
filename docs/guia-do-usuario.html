Dindin

Guia do usuario

Este manual foi escrito para ajudar no uso diario do Dindin: entrar no sistema, cadastrar contas, atualizar os lancamentos do mes, consultar detalhes e gerenciar a propria conta.

Versao do documento: 2026-03-21

Antes de comecar

O Dindin roda localmente no navegador e salva os dados no computador.

Endereco padrao: http://127.0.0.1:3030

Tema: o botao no topo alterna entre modo claro e escuro.

1. Como acessar

  1. Abra o projeto e rode o comando npm start.
  2. No navegador, acesse http://127.0.0.1:3030.
  3. Entre com seu usuario e senha.

Administrador inicial: em instalacoes novas, as credenciais sao definidas pelo responsavel no ambiente protegido do servidor. O sistema nao possui senha padrao.

2. O que existe no sistema

Tela Para que serve
Visao geralMostra os meses salvos, o salario do mes e o resumo financeiro.
CadastrosCria os gastos recorrentes que servem de base para os meses.
LancamentosPermite atualizar valor, ciclo, status e observacao dos gastos do mes atual.
DetalhesMostra todos os gastos materializados no mes selecionado.
ContaEditar perfil, trocar senha e sair.
AdministracaoApenas para administradores: criar e editar usuarios locais.

3. Passo a passo de uso

3.1 Escolher o mes

Use o seletor de mes no topo da tela. O Dindin sempre trabalha dentro do mes selecionado.

  • Se o mes ja estiver salvo, seus dados serao exibidos imediatamente.
  • Se o mes ainda nao existir, ele entra em pre-visualizacao e sera gravado quando voce salvar algo nele.

3.2 Informar o salario do mes

Na tela Visao geral, preencha o campo Salario do mes e clique em Salvar salario.

Esse valor vale apenas para o mes selecionado.

3.3 Criar um cadastro de gasto

Na tela Cadastros, informe:

  • Nome do gasto
  • Valor
  • Pagar na: inicio do mes ou quinzena
  • Forma de pagamento
  • Observacao, se necessario
  • Valor varia todo mes, se o valor nao for fixo

Ao salvar, o cadastro passa a fazer parte do mes atual.

3.4 Atualizar lancamentos do mes

Na tela Lancamentos, cada card representa um gasto do mes. Voce pode:

  • editar o valor daquele mes
  • trocar o ciclo (inicio do mes ou quinzena)
  • alterar o status para Pendente, Pago ou Guardado
  • salvar uma observacao
  • excluir o gasto daquele mes

3.5 Consultar detalhes

Na tela Detalhes, voce ve todos os gastos gerados para o mes selecionado em formato de leitura. Essa tela e util para conferencia rapida, inclusive em dark mode.

3.6 Excluir um mes

Na tela Visao geral, use o botao Excluir mes.

Esse processo remove os lancamentos do mes e o proprio registro do mes. Use com cuidado.

4. Como o sistema se comporta

Cadastro fixo

Quando um gasto e fixo, ele pode aparecer automaticamente em meses futuros ja salvos.

Cadastro variavel

Quando um gasto e marcado como variavel, ele nao e replicado automaticamente para meses futuros que ainda nao tenham o lancamento.

Historico mensal

Alterar o valor de um lancamento afeta o mes atual, nao os meses anteriores.

Resumo do mes

Os cards de resumo mostram salario, totais, pendencias e saldo projetado com base no mes selecionado.

5. Conta e seguranca

5.1 Editar perfil

Pelo menu da conta no topo, voce pode alterar o nome de exibicao e a foto de perfil.

5.2 Trocar senha

Use a opcao Trocar senha no menu da conta.

5.3 Esqueci a senha

Na tela de login, clique em Esqueceu a senha?.

Se o servidor estiver configurado com SMTP, o sistema envia um link de redefinicao valido por 60 minutos.

6. Funcao de administrador

Usuarios administradores enxergam a opcao Administracao no menu da conta.

  • Listar usuarios
  • Criar novo usuario
  • Editar nome, usuario, e-mail e permissao de admin

7. Dicas praticas

  • Defina primeiro o salario do mes e depois ajuste os lancamentos.
  • Use observacoes para registrar regras, datas de vencimento e lembretes.
  • Use o tema escuro se preferir trabalhar com menos brilho.
  • Ao excluir um mes, revise antes se nao ha informacoes que precisam ser mantidas em historico.

8. Problemas comuns

Problema O que fazer
Pagina nao abreConfirme que o servidor foi iniciado com npm start e que a porta 3030 nao esta sendo usada por outro processo antigo.
Sessao expirouEntre novamente. Reiniciar o servidor encerra as sessoes em memoria.
Reset de senha nao envia e-mailVerifique se o servidor foi configurado com as variaveis SMTP.
Mes ainda nao salvoSalve salario ou algum cadastro/lancamento no mes para persisti-lo.
